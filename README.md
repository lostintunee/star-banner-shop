# Star Banner Shop

Лендинг с баннерами + Telegram-бот, который продаёт фото/видео за Telegram Stars.

## Как это работает

1. Вы пишете боту в личку, присылаете фото или видео и назначаете цену в звёздах.
   Бот сохраняет файл и возвращает **код товара**.
2. В админке сайта (`/admin`) вы создаёте баннер: своя картинка, заголовок, текст,
   и вставляете код товара из шага 1. Сайт сам генерирует прямую ссылку на оплату
   (`createInvoiceLink`) и подтягивает цену.
3. На главной странице появляется баннер с кнопкой «Купить», на которой уже
   показана цена (например «Купить — 100 ⭐»).
4. Пользователь нажимает кнопку → сразу открывается экран оплаты Telegram Stars
   (без чата с ботом и кнопки Start) → после оплаты бот присылает купленное
   фото/видео.

Если задать `PUBLIC_BASE_URL` (публичный https-адрес сайта после деплоя), в
карточке оплаты будет показываться широкое превью — картинка самого баннера.

## Запуск

```bash
npm install
cp .env.example .env   # заполнить токен бота, пароль админки и т.д.
npm start
```

Откроется:
- сайт — `http://localhost:PORT/`
- админка — `http://localhost:PORT/admin` (пароль из `ADMIN_PASSWORD`)
- бот запустится автоматически, если задан `BOT_TOKEN`

## Настройка `.env`

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather) (`/newbot`)
- `BOT_USERNAME` — username бота без `@`
- `ADMIN_TELEGRAM_ID` — ваш числовой Telegram ID. Если оставить пустым, бот
  ответит на любое ваше сообщение вашим ID — скопируйте его в `.env` и
  перезапустите бота.
- `ADMIN_PASSWORD` — пароль от `/admin`
- `SESSION_SECRET` — любая случайная строка

## Добавление товара через бота

Напишите боту (только с аккаунта, чей ID указан в `ADMIN_TELEGRAM_ID`):

1. Отправьте фото или видео.
2. Бот спросит цену — напишите число звёзд, например `100`.
3. Бот пришлёт код товара и ссылку вида `https://t.me/bot_username?start=abc123`.

## Создание баннера

В `/admin`:
- загрузите картинку баннера (то, что видят посетители сайта — не обязательно
  совпадает с самим платным видео);
- заголовок и текст — любые, под вирусный/кликбейт стиль;
- код товара — вставьте код, полученный от бота;
- username бота — обычно уже подставлен по умолчанию.

Баннер сразу появится на главной странице.

## Технические детали

- Стек: Node.js, Express + EJS, grammY (Telegram Bot API), без базы данных —
  всё хранится в `data.json` (создаётся автоматически).
- Оплата — нативные Telegram Stars (`currency: "XTR"`), провайдер-токен не
  нужен, Telegram обрабатывает всё сам.
- Файлы (фото/видео) физически не скачиваются на сервер — хранится только
  Telegram `file_id`, бот пересылает их из Telegram при доставке покупки.

## Деплой в продакшн

Для постоянной работы (не с домашнего компьютера) разверните этот же код на
любом VPS/хостинге с Node.js (например Railway, Render, обычный VPS + pm2).
Приложение слушает один порт (`PORT`) и polling-ом получает апдейты от
Telegram — вебхук не обязателен.
